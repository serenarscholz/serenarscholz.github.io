## ARQ

ARQ is a new atmospheric river detection algorithm based on moisture-weighted winds. Unlike methods based on IVT or IWV, it can perform well across a variety of warm and cold climate states without tuning or arbitrary threshold decisions.\
When the associated paper is published, code and documentation will be made available on GitHub. AR tags will also be submitted for inclusion in the [Atmospheric River Tracking Method Intercomparison Project (ARTMIP)](https://ncar.github.io/ARTMIP/intro.html).

## Island

Island is a modification to the hierarchical modeling framework [Isca](https://execlim.github.io/IscaWebsite/) that allows highly-customizable land surfaces, including a simple representation of plants based on stomatal conductance.\
Users can create and input custom maps of albedo, surface roughness, and stomatal conductance to create customized heterogeneous land surface.
Once the modifications are fully tested and integrated into the Isca codebase, code and documentation will be made available on GitHub.
